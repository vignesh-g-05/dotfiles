## Features

- 3 themes with 6 variants
- Rofi-based variant switcher with previews
- Custom Waybar setup
- SwayNC notifications + SwayOSD integration
- Styled Hyprlock with dynamic backgrounds
- Smooth wallpaper transitions
- Consistent UI across all components

---

## Components

- **WM:** Hyprland
- **Bar:** Waybar
- **Notifications:** SwayNC
- **OSD:** SwayOSD
- **Terminal:** Kitty
- **Launcher:** Rofi
- **Network Applet:** Orbit
- **File Manager:** Nautilus

## Installation

```sh
git clone https://github.com/vignesh-g-05/dotfiles ~/dotfiles
cd ~/dotfiles
./install.sh
```

### Supported

- Fedora ✅
- Arch ⚠️ (experimental)

> This setup is not fully plug-and-play. Basic knowledge of Hyprland is expected.

---

## Theme System

Themes are organized into variants with a unified structure.

Switch variants using a **Rofi-based selector with live previews**.

Each variant updates:

- Wallpaper
- Hyprlock background
- Fastfetch image
- UI colors
- gtk theme
